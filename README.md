# LAS VENENOSAS — Verification Bot

Serverless Telegram bot for private model-verification requests.

## Current foundation

- Telegram webhook endpoint: `/api/telegram-webhook`
- Private forum group configured through `VERIFY_GROUP_ID`
- Owner-only `/testtema` command to verify that the bot can create forum topics
- Webhook secret validation through Telegram's `X-Telegram-Bot-Api-Secret-Token` header
- No verification evidence is made public

## Required environment variables

| Variable | Purpose |
| --- | --- |
| `BOT_TOKEN` | Token generated by @BotFather |
| `VERIFY_GROUP_ID` | Private forum group ID |
| `OWNER_ID` | Numeric Telegram ID of the bot owner |
| `WEBHOOK_SECRET` | Random secret configured on the Telegram webhook |
| `WEBHOOK_BASE_URL` | Optional public URL of the deployed webhook |

`TGCloud_TOKEN` is a hosting/platform credential if supplied by TGCloud. It is not automatically the Telegram BotFather token. Keep platform credentials separate from `BOT_TOKEN`.

## First connection test

1. Deploy this repository to the selected TGCloud serverless runtime.
2. Configure the environment variables above.
3. Register the deployed endpoint as the Telegram webhook, using the same `WEBHOOK_SECRET`.
4. Send `/testtema` to the bot in a private chat.
5. The owner-only command creates a clearly named test topic in the verification forum and posts a confirmation inside it.

## Verification workflow — planned

Each applicant will receive a stable request ID and a dedicated forum topic. The bot will route the video message, Zing photo and sales references to that topic, track missing evidence, and notify authorized reviewers.

Persistent request-to-topic mapping and audit history must be backed by the selected database before enabling real applications. Do not use process memory for production state.

## Privacy and safety

- Verification evidence is private and must never be copied to the public gallery.
- Only explicitly authorized administrators may review evidence.
- Do not store BotFather tokens, TGCloud credentials, database credentials, or webhook secrets in Git.
- A spoken age statement or appearance alone is not sufficient proof of adulthood.
